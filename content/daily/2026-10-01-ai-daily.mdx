### 3. AI Agent 共享凭据安全漏洞

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-10-01/c7fca0ae1434.jpg)

AI Agent 共享凭据安全漏洞：VentureBeat 调查显示，在 37 家已部署 AI Agent 的企业中，22 家（约 60%）仍让 Agent 共享 API 密钥或服务账户凭据，而非使用独立身份标识。

尽管 Okta、Cisco 等厂商已推出专用 Agent 身份工具，但多数企业仍沿用传统权限扩展方案，导致 Agent 安全事件频发且难以追责。

### 5. LLM 推理优化技术详解

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-10-01/40cfb6bdc6c3.png)

LLM 推理优化技术详解：LLM 推理瓶颈在于 KV Cache 而非计算速度，vLLM 通过 PagedAttention 和 Continuous Batching 显著提升并发能力。

Chunked Prefill 避免长文档阻塞，Speculative Decoding 在特定场景下加速生成，vLLM 默认开启多项优化。

vLLM 配置中 max-num-seqs 限制并发数，max-model-len 限制显存，监控 kv_cache_usage_perc 可优化部署。
