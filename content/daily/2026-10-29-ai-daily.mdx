### 2. AI Agent 重复执行 SQL 254 次

AI Agent 重复执行 SQL 254 次：Funnel 团队在 Reef 平台测试中发现，GLM-5.2 模型因未识别工具限制，成功但无效地重复执行同一 SQL 查询 254 次，导致任务耗时比 Claude Opus 长 14%。

### 3. contextWatcher 开源

contextWatcher 开源：contextWatcher 是开源的 Rust 上下文清理工具，通过影子去重、工具输出修剪和尾部规则固定，解决 LLM 上下文膨胀导致的注意力分散问题。

该工具在本地 CPU 运行（耗时<2ms），保留 KV 缓存和提示缓存，实测将 28k 上下文预填充时间从 170 秒降至 1.6 秒，且代码完整无损。

支持 llama.cpp/vLLM 等推理引擎，通过一行命令即可安装，适合本地 AI 编程和智能体开发场景。

📎 [原文链接](https://news.ycombinator.com/item?id=50274683)
