### 3. Anthropic Claude 文本水印机制解析

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-08-23/220d9da87520.jpg)

Anthropic Claude 文本水印机制解析：Anthropic 宣布对 Claude 模型输出添加水印，旨在通过隐藏标记识别 AI 生成文本。

技术原理是在 LLM 生成下一个 token 时，通过算法微调概率分布，在不影响人类阅读体验的前提下植入可检测信号。

### 4. Decode 开源课程：Agent 循环三种模式

Decode 开源课程：Agent 循环三种模式：Decode 开源课程解析了运行 Agent 循环的三种模式：交互式在线、远程离线和异步在线，并对比了各自的延迟与成本模型。

交互式模式受限于延迟，适合低延迟 API；远程和异步模式受限于吞吐量，适合按 GPU 小时计费的批处理场景。

课程指出，1000 个文档在前沿 API 下成本约 97 美元，而批处理 GPU 时间仅需约 13 美元，强调了 Harness 编排对 Agent 性能的关键影响。
