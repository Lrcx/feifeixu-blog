### 1. Z.ai 发布 GLM-5.3-Flash

Z.ai 发布 GLM-5.3-Flash，这是 GLM-5 系列首款原生多模态 MoE 模型，拥有 3200 亿总参数和 180 亿激活参数，支持 100 万 Token 上下文及图像视频输入。

该模型采用混合注意力机制，在 Terminal-Bench 2.1 中得分 84.3，接近 Claude Opus 4.8，且价格仅为前代十分之一，API 定价为输入 $0.15/M、输出 $0.50/M。

模型以 MIT 许可证在 Hugging Face 开源权重，本地部署需约 306 GiB 显存及 Hopper 架构 GPU，开发者可通过 API 或 GLM Coding Plan 订阅使用。
