### 3. LLM API 权重隐写外泄漏洞

LLM API 权重隐写外泄漏洞：MATS Research 与 Anthropic 联合发布论文，揭示 LLM 推理 API 存在隐蔽信道漏洞，攻击者可通过控制 token 选择及 logprobs 将模型权重编码进正常回复中。

该攻击利用 API 返回的候选 token 概率分布，在看似正常的文本生成中隐藏数据，导致模型权重在监控外被完整窃取。

防御方案为推理验证（Inference Verification），通过固定随机种子在可信环境重放请求比对 logit，目前 OpenAI 等大厂已停止返回 logprobs 以阻断此信道。

📎 [原文链接](https://weights-exfil.github.io/model-weights-exfiltration/)
