### 1. Meta Muse Code 发布

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-08-06/22b887796f33.jpg)

Meta Muse Code 发布：Meta 发布基于终端的 AI 编程代理 Muse Code 及底层模型 Muse Spark 1.2，主打持久异步后台代理与并行工作树隔离，支持 20 小时长周期任务自动恢复。

Muse Spark 1.2 在 Terminal-Bench 2.1 得分 82.9%，API 提供标准层与贡献层，后者输入 0.10 美元/百万 token 但允许数据用于训练。

通过单行命令安装，需绑定 Meta 账户及支付方式，标志着 Meta 从开源转向专有 AI 编程工具生态。

📎 [原文链接](https://venturebeat.com/orchestration/meta-enters-the-ai-coding-wars-with-muse-spark-1-2-and-muse-code-with-persistent-async-background-agents)


### 2. NVIDIA 发布 Alpamayo 2 Super

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-08-06/7d1c85f20db4.webp)

NVIDIA 发布 Alpamayo 2 Super：NVIDIA 发布 340 亿参数视觉-语言-动作（VLA）模型 Alpamayo 2 Super，采用 OpenMDW-1.1 许可开源，支持商业部署。该模型基于 Cosmos 3 骨干网络，单次推理可输出轨迹、因果解释及元动作，LingoQA 测试得分近 40 款模型第一。

模型在 AlpaSim 闭环评估中得分 1.50，6.4 秒预测误差仅 0.911 米，可运行于单张 H100 显卡。训练数据包含 11.5 万小时视频，可大幅缩短自动驾驶车队数据标注周期。

📎 [原文链接](https://www.marktechpost.com/2026/08/05/nvidia-alpamayo-2-super-open-vla-model-autonomous-driving/)
