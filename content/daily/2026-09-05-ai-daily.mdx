### 3. GitHub HydraFusion 发布

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-09-05/45d1b1668eed.jpg)

GitHub HydraFusion 发布：GitHub 发布 HydraFusion 模型路由方案，通过 Copilot CLI 提供预览版，将编程请求动态路由至不同模型或组合策略。
