### 5. Perplexity Computer Agent 训练方法升级

![](https://cdn.jsdelivr.net/gh/Lrcx/image-repo@master/ai-daily-report/2026-09-26/e950e1ff4989.png)

Perplexity Computer Agent 训练方法升级：Perplexity 发布 Computer Agent 后训练研究，利用提示引导的自我蒸馏在真实错误上训练模型，实时 A/B 测试显示工具调用失败率从 2.24% 降至 1.77%。

### 6. Hurray 开源张量互换规范

Hurray 开源张量互换规范：Hurray 是 Pascal Gillet 开源的 AI/ML 张量数据互换规范，旨在统一描述张量的类型、形状、内存布局、量化、设备放置及组合属性。
