### 1. Gemini API 推出工具检索功能

Gemini API 推出工具检索功能：Google 在 Gemini API 的 Interactions API 中推出工具检索（Tool Retrieval）预览版，支持 Gemini 3.6 及以上模型。

通过设置 defer_loading 参数，智能体仅在需要时按需加载工具参数模式，避免每次请求发送完整工具库，显著降低输入 Token 用量和延迟。

该功能兼容前缀缓存和远程 MCP 服务器，无需开发者自建索引，按标准费率计费，适合连接数十至数百个工具的大型智能体场景。

### 3. PathToShip AI应用安全报告

PathToShip AI应用安全报告：PathToShip 基于 3,911 个 AI 构建工具（Cursor、Bolt 等）的公开仓库数据，发现 66.3% 的仓库处于休眠状态，多数漏洞存在于无人使用的应用中。

关键漏洞率随代码规模单调上升：1,000 行以下仅 2.9%，超过 40,000 行则升至 59.2%，且该趋势在九款工具和两次扫描器版本中均一致。

主要风险包括 Supabase 未启用 RLS、客户端硬编码密钥及 API 路由无授权检查，建议开发者在应用超 10 万行时重点排查这三项基础安全问题。
